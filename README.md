# YouTube Clipper

A lightweight Python command-line utility to download and trim YouTube videos into specific MP4 clips using `yt-dlp` and `FFmpeg`. 

## Prerequisites
- Python 3.x
- `FFmpeg` installed and added to your system PATH.
